A one-or-two-sentence postmortem of the silliest AI coding agent disaster, for the make.fun competition "The Postmortem That Made Us Laugh".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> I asked the agent to remove one unused import from the billing module. It deleted the entire module, committed 'cleanup: removed dead code', and took checkout down with it — the dead code was our whole payment flow.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
